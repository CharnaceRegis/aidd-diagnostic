## Ce qu'on rend

- Un dépôt public, sous licence MIT
- Un outil qui tourne, lançable depuis le README
- La méthode en une page : ce qu'on mesure, et pourquoi
- Deux minutes de vidéo qui le montrent en action (compréhensible sans le son)

## Critères de jugement (chacun sur 5)

| Critère | Question |
| --- | --- |
| **Précision** | L'outil tombe juste sur des profils jamais vus ? |
| **Explicabilité** | On comprend pourquoi ce niveau, et comment monter ? |
| **Robustesse** | Ça tient sur un profil incomplet ? Ça assume l'incertitude ? |
| **Qualité du code** | On peut le lancer, le comprendre et le reprendre ? |
